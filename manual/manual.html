  4. 내보내서 제출하기양식 그대로 PDF나 사진으로 만들어 카톡으로 보내요. 일주일 치를 한 파일로 묶을 수도 있어요.

1시작하기

앱 열기

표지의 QR 코드를 찍거나, 아래 주소를 열어 주세요. 설치나 회원가입은 필요 없어요.

카카오톡 안에서 바로 열지 마세요

카톡 안에서 링크를 누르면 카톡 전용 브라우저로 열려서, 쓴 내용이 제대로 저장되지 않을 수 있어요. 이때는 오른쪽 그림처럼 노란 안내가 떠요.

  • 다른 브라우저로 열기를 누르면 기본 브라우저로 다시 열려요.
  • 버튼이 안 되면 카톡 화면의 메뉴(⋮ 또는 ⋯)에서 "다른 브라우저로 열기"를 눌러 주세요.
  • 아이폰은 Safari, 안드로이드는 Chrome으로 열면 돼요.

홈 화면에 추가하기

한 번 추가해 두면 앱처럼 아이콘을 눌러 열 수 있어요.

아이폰 (Safari)아래쪽 공유 ⬆ 버튼 → 홈 화면에 추가 → 추가
안드로이드 (Chrome)오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치

앞으로는 홈 화면 아이콘으로만 열어 주세요. 쓴 기록은 브라우저마다 따로 저장돼요. Safari, 홈 화면 앱, Chrome처럼 여러 곳에서 번갈아 열면 기록이 서로 안 보여요.

처음 열면

"작성한 큐티는 이 폰에만 저장돼요"라는 안내가 한 번 나와요. 확인을 누르면 다시 나오지 않아요.

쓴 큐티는 내 폰 안에만 저장돼요. 서버나 다른 사람에게 전송되지 않고, 내가 직접 내보낸 파일만 밖으로 나가요.

2큐티 쓰기

맨 위 탭에서 작성을 누르면 큐티일기 양식과 같은 순서로 칸이 나와요.

칸 채우기

조 · 이름처음 한 번만 쓰면 다음부터 자동으로 채워져요.
날짜오늘 날짜가 기본으로 들어가요. 밀린 큐티는 날짜를 눌러 바꿔 주세요.
본문 · 제목예) 요한복음 15:1-8 / 포도나무와 가지
요약 · 묵상
적용 · 기도		칸은 쓰는 만큼 늘어나요. 줄을 바꾸면 결과물에도 그대로 반영돼요.

본문 쉽게 쓰기

  • 다음 본문 제안: 본문 칸이 비어 있으면, 지난번 본문이 끝난 바로 다음부터 시작하는 "다음 본문: 요한복음 15:1-"이 보여요. 넣기를 누르고 끝나는 절만 이어서 쓰면 돼요. 장이나 책이 끝났으면 다음 장, 다음 책으로 넘어가요.
  • 책 이름 자동완성: "요"처럼 앞글자나 약어만 써도 요한복음 요엘 같은 후보가 나와요. 누르면 전체 이름이 들어가요.

저장은 자동이에요

글자를 입력하면 바로 저장되고, 화면 아래에 "자동 저장됨 21:05"처럼 표시돼요. 앱을 닫거나 폰을 꺼도 내용은 남아 있어요.

새로 쓰기 · 예전 큐티 고치기

맨 아래 새로 쓰기를 누르면 빈 양식이 열려요. 예전 큐티는 모아보기에서 누르면 작성 화면에 열리고, 고친 내용도 자동으로 저장돼요.

3내보내기 · 제출하기

다 쓴 큐티는 큐티일기 양식 그대로 PDF나 사진으로 만들어져요.

한 장 내보내기

  1. 작성 화면 아래의 미리보기 · 내보내기를 눌러요.
  2. 완성된 양식을 미리 보여 줘요.
  3. 원하는 버튼을 눌러요.
공유저장
PDF카톡 등으로 바로 보내기폰에 파일로 저장
사진카톡 등으로 바로 보내기폰에 사진으로 저장

컴퓨터에서는 공유 버튼이 안 보일 수 있어요. 이때는 저장을 눌러 주세요.

일주일 치 묶어서 내보내기

모아보기의 주별 목록에서 이 주 내보내기를 누르면, 그 주의 큐티가 날짜순으로 PDF 한 파일에 묶여요. (4장 참고)

파일 이름

큐티일기_3조_홍길동_2026-10-28.pdf
큐티일기_3조_홍길동_2026-10-21~2026-10-27.pdf

내용이 길어도 괜찮아요. 글자 크기가 자동으로 조금 줄어서 한 장에 맞춰져요. 그래도 넘치면 다음 장으로 이어져요.

4모아보기 · 달력

모아보기 탭에서 지금까지 쓴 큐티를 한눈에 볼 수 있어요.

① 작성 횟수

맨 위에 이번 주 · 이번 달 · 전체 동안 큐티를 쓴 날 수가 나와요. 같은 날 두 개를 써도 하루로 세요.

연속은 며칠째 빠짐없이 쓰고 있는지 보여 줘요. 오늘 아직 안 썼으면 어제까지 센 숫자가 나오고, 하루를 건너뛰면 다시 1부터 세요.

② 달력

  • 큐티를 쓴 날은 검은 동그라미로 표시돼요.
  • ‹ › 버튼으로 다른 달을 볼 수 있어요.
  • 표시된 날짜를 누르면 그날 쓴 큐티 내용이 아래에서 올라와요. 여기서 바로 수정하기나 내보내기를 할 수 있어요.

③ 주별 목록

  • 달력 아래에 쓴 큐티가 한 주씩 묶여서 나와요.
  • 이 주 내보내기를 누르면 그 주 전체가 PDF 한 파일로 만들어져요.
  • 큐티 제목을 누르면 작성 화면에서 열려요.
  • ✕를 누르면 휴지통으로 옮겨져요. (7장 참고)

한 주를 무슨 요일부터 셀지는 설정 → 한 주의 시작에서 고를 수 있어요. 조 모임 요일에 맞춰 일요일 · 월요일 · 수요일 중에서 골라 주세요.

5검색

예전에 쓴 큐티를 낱말로 찾을 수 있어요.

  1. 모아보기의 작성 횟수 아래 검색창을 눌러요.
  2. 찾을 낱말을 써요. 쓰는 동안 바로 결과가 나와요.
  3. 결과를 누르면 그날 큐티 전체 내용이 열려요. 거기서 수정하기나 내보내기도 할 수 있어요.

이렇게 찾아요

찾는 곳본문, 제목, 요약, 묵상, 적용, 기도를 모두 찾아요.
여러 낱말"포도나무 열매"처럼 띄어 쓰면 두 낱말이 모두 들어간 큐티만 나와요.
결과 표시날짜와 제목, 찾은 낱말이 들어간 문장이 나오고, 찾은 낱말은 노란색으로 표시돼요.
책으로 찾기"요한복음"이나 "시편 23"처럼 본문으로도 찾을 수 있어요.

검색창을 비우면 달력과 주별 목록이 다시 나와요.

6날짜 골라 내보내기

원하는 날짜만 골라서 PDF 한 파일로 묶을 수 있어요. 2주 치를 한 번에 내거나, 빠진 날만 따로 낼 때 편해요.

  1. 모아보기 달력 오른쪽 위의 날짜 골라 내보내기를 눌러요.
  2. 달력에서 날짜를 골라요. 고른 날은 파란색으로 바뀌어요.
  3. 아래에 나오는 "○개 선택됨" 막대에서 내보내기를 눌러요.

날짜를 고르는 세 가지 방법

누르기날짜를 누를 때마다 선택되고, 한 번 더 누르면 해제돼요.
끌기날짜를 누른 채로 손가락을 끌면 지나간 날이 한꺼번에 선택돼요. 이미 선택된 날에서 시작해서 끌면 한꺼번에 해제돼요.
빠른 선택이번 주 지난 주 이 달 전체 버튼을 누르면 해당 기간이 한 번에 선택돼요. 여러 개를 이어서 누르면 기간이 더해져요. 전체 해제로 처음부터 다시 고를 수 있어요.
  • 큐티를 쓴 날만 고를 수 있어요. 쓰지 않은 날은 흐리게 보여요.
  • 다른 달로 넘어가도 고른 날짜는 그대로 남아 있어요. 9월 말부터 10월 초까지처럼 달을 넘겨서도 고를 수 있어요.
  • 그만두려면 취소를 눌러요.

7설정 · 백업 · 삭제

도움말

설정 맨 위의 사용 설명서 보기 (PDF)를 누르면 이 설명서가 열려요. 친구에게 그대로 전달해도 돼요.

기본 정보

조 · 이름을 바꾸면 새로 쓰는 큐티에 반영돼요. 한 주의 시작은 주별 목록과 "이번 주" 계산에 쓰여요.

보관 기간

기본값은 계속 보관이에요. 12주 · 4주 · 1주로 바꾸면 그보다 오래된 큐티는 자동으로 지워져요. 기간을 바꿀 때 바로 지워지는 큐티가 있으면 몇 개인지 먼저 알려 줘요.

백업 · 불러오기

기록은 이 폰에만 있어서, 폰을 바꾸거나 브라우저 기록을 지우면 사라져요. 가끔 백업 파일 저장을 눌러 파일로 보관해 주세요.

  • 새 폰에서는 백업 불러오기로 그 파일을 열면 돼요. 이미 있는 기록과 겹치지 않게 합쳐져요.
  • 마지막 백업 후 2주가 지나면 작성 화면 위에 알림이 떠요.

삭제와 휴지통

  • 지운 큐티는 바로 사라지지 않고 휴지통에 30일 동안 보관돼요. 휴지통은 모아보기 맨 아래에 있고, 복원으로 되살릴 수 있어요.
  • 모든 큐티 삭제를 누르면 전부 휴지통으로 옮겨져요.
  • 완전히 지우려면 휴지통 비우기를 눌러요. 이렇게 지운 건 되살릴 수 없어요.

8자주 묻는 질문

열자마자 노란 안내가 떠요.
카톡이나 인스타그램 같은 앱 안에서 링크를 열었을 때 나오는 안내예요. 다른 브라우저로 열기를 누르거나 메뉴에서 Safari·Chrome으로 열어 주세요. 그다음 홈 화면에 추가해 두면 다시 뜨지 않아요.
다음 본문 제안이 우리 교재와 달라요.
앱은 교재 일정을 모르고, 지난번 본문이 끝난 바로 다음 구절부터 제안해요. 교재와 다르면 제안을 쓰지 말고 직접 쓰면 돼요. 자동으로 들어가지는 않고, 넣기를 눌렀을 때만 들어가요.
내가 쓴 큐티를 다른 사람이 볼 수 있나요?
아니요. 기록은 내 폰 브라우저 안에만 저장되고 어디에도 전송되지 않아요. 앱을 만든 사람도 볼 수 없어요. 내가 직접 내보내서 보낸 파일만 상대방이 볼 수 있어요.
폰을 바꾸면 기록이 옮겨지나요?
자동으로는 옮겨지지 않아요. 예전 폰에서 설정 → 백업 파일 저장을 하고, 새 폰에서 백업 불러오기로 그 파일을 열어 주세요.
기록이 갑자기 안 보여요.
다른 브라우저로 열었을 가능성이 커요. 예를 들어 홈 화면 앱 대신 Safari로 열었거나, 카톡 안에서 열었을 수 있어요. 기록은 원래 쓰던 곳에 그대로 있으니, 평소에 쓰던 홈 화면 아이콘으로 열어 보세요.
기록이 지워질 수 있는 경우는요?
브라우저 설정에서 방문 기록·사이트 데이터를 삭제했을 때, 아이폰에서 홈 화면 아이콘을 삭제했을 때, 폰을 초기화했을 때예요. 대비하려면 가끔 백업해 두세요. 제출한 PDF도 백업 역할을 해요.
인터넷이 없어도 쓸 수 있나요?
네. 한 번이라도 인터넷이 될 때 열어 두면, 그다음부터는 비행기 모드에서도 쓰고 PDF까지 만들 수 있어요. 카톡으로 보내는 것만 인터넷이 필요해요.
앱이 업데이트됐다는데 화면이 그대로예요.
앱을 완전히 닫았다가 다시 열어 주세요. 그래도 그대로면 10분쯤 뒤에 한 번 더 열어 주세요. 업데이트해도 기존 기록은 그대로 남아요.
공유 버튼을 눌러도 카톡이 안 보여요.
공유 목록을 옆으로 넘기거나 더보기에서 카카오톡을 찾아 주세요. 그래도 안 되면 저장으로 파일을 저장한 뒤, 카톡 대화방에서 파일이나 사진으로 첨부하면 돼요.
같은 날 큐티를 두 개 써도 되나요?
네. 둘 다 저장되고, 달력에서 그 날짜를 누르면 둘 다 보여요. 작성 횟수에서는 하루로 세요.
